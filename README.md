# 🏰 Shadow Defense 3.0 — Ultimate Edition

Tower Defense на чистом HTML/CSS/JS. Работает в браузере на телефоне и ПК.

## 🎮 Возможности
- 8 типов башен × 4 уровня прокачки
- 4 героя с навыками Q/W/E
- 12 монстров + 3 босса с механиками
- 4 уровня + Endless-режим
- 15 достижений с наградами
- Погодные эффекты (дождь/снег/буря)
- Система типов урона, криты, щиты
- Престиж-система (бонусы за перерождение)
- Сохранения в браузере
- Звук (WebAudio-синтез)

## 🎯 Управление
- Тап по карте → поставить башню
- Тап по башне → апгрейд/продажа
- Q/W/E → навыки героя
- Space → начать волну
- P → пауза

## 🛠️ Технологии
Canvas 2D, WebAudio, LocalStorage, нулевые зависимости.
